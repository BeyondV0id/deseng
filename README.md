# Fieldnotes

A React + TypeScript library for collecting design references, tools, and useful links. Built with Vite and Tailwind CSS v4.

## Run locally

```sh
npm install
npm run dev
```

## What’s here

- A searchable directory organized into the 20 categories from [Design Engineer Tools](https://designengineer.tools/).
- Favorites and custom folders, saved in browser local storage.
- Add your own link and choose a category.
- Fluid Hover on the compact sidebar navigation, using the [Fluid Functionalism component](https://www.fluidfunctionalism.com/docs/fluid-hover).
- Reicon React icons, imported by glyph to keep the icon set consistent.
- Built on the [Arc](https://uiarc.dev) component library, vendored under `src/components/arc`.
- Locally bundled Inter, used for both display and body text.
- Responsive sidebar and native, keyboard-accessible dialogs.
- Folder-card animation adapted from [Rare UI](https://www.rareui.com/components/foldercomponent).

The seed directory was collected from Design Engineer Tools on 21 October 2026. User-created resources and folder assignments stay in the current browser profile.

Conventions for working in this repo live in [AGENTS.md](./AGENTS.md).
